# Run Please

A simple platforming rooms-style game where every room has multiple floors, made for the Terra Hackathon.

> **Note:** The game isn't complete yet or near to.

---

##  How to Play
- **Move:** Arrow keys
- **Jump:** Spacebar

###  Play
You can play it online by clicking here:  
 [Play on GX.games](https://gx.games/games/8qdhk3/run-please/tracks/b2a47b1c-ae85-4c32-b031-28a525fe5039/)  
*(Note: If the link didn't work for you, try using a VPN)*
